For a marketing landing page, the hero image typically goes:

- **Above the fold**, right side or centered, paired with the headline/CTA on the left (or below if centered).
- Common pattern: H1 + subhead + CTA on the left half, hero visual on the right half (desktop); stacked on mobile with visual below the copy.
- If the product is visual-first (screenshots, product shots), make the hero image dominant. If it's concept-first, keep it secondary to the headline.
